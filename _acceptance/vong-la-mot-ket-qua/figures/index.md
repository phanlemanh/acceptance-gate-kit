## Đề bài hình `khoang-co-hai-nhanh`

- Loại: so hai nhánh (cạnh nhau, trái/phải), nguồn: design doc §3 và §4.1.
- Nhánh A (máy khuyên): hồ sơ đã giao → đồng hồ cỡ in bảng (n · lượt TB · % chạm trần) mỗi lần chạy →
  chủ kho đọc ở mốc → sửa khối khoảng năm dòng trong SKILL nếu số nói khác → răng đọc khối.
- Nhánh B: hồ sơ đã giao → máy tự suy khoảng mỗi lần chạy → răng dùng khoảng suy ra.
- Nhãn số dưới nhánh B: kit 8–10 → 62 % chạm trần, ≤ 7 → 33 %, ≥ 13 → 64 % (cỡ không dự báo lượt) —
  khoảng suy ra ở kit vô nghĩa; crm 8–10 → 22 %, ≥ 13 → 62 %.
- AC liên quan: AC-1 (khối một nguồn), AC-7 (đồng hồ).
