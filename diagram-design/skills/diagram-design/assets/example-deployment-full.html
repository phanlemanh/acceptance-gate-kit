One environment per diagram. This is where each unit of the platform actually runs in ap-southeast-1 — three deployments on one cluster, all state parked outside it.

THE HEADLINE

api ×3 is the ceiling

Ingress and worker sit comfortably at two replicas. Every request path converges on api, and three pods is where the node group runs out of headroom at peak.

One cluster, three deployments

  • ingress ×2 — TLS termination
  • api ×3 — the request path
  • worker ×2 — queue consumers

State stays outside

Postgres, Redis, and S3 are managed services in the region but never in the cluster — so a node roll is a restart, not a data event.
