## T2 — `unquoteScalar` + `resolveConfigKey` (GREEN cho BG1, BG2)

**Files:** `lib/evidence-core.cjs`

Thêm hàm, xuất khẩu qua `module.exports`, thay khối lá của `resolveConfigKey`:

```js
function unquoteScalar(raw) {
  const s = String(raw == null ? '' : raw);
  if (/^"(?:[^"\\]|\\.)*"$/.test(s)) return s.slice(1, -1).replace(/\\(["\\])/g, '$1');
  if (/^'(?:[^']|'')*'$/.test(s)) return s.slice(1, -1);
  return s;
}
```

Chú thích ngay trên hàm phải nói VÌ SAO: mệnh đề cũ là phép thay thế có-neo dạng
lựa-chọn, gỡ nháy đầu và nháy cuối ĐỘC LẬP nhau, nên một chuỗi chỉ tình cờ kết thúc
bằng nháy vẫn mất ký tự đó — và vì nó chỉ cắt vỏ nên không biết gì về escape bên trong
vỏ. Nêu đích danh chuỗi xanh-giả bốn bước và hồ sơ `release-2-11-0`.

**Verify:** `node tests/scripts/bo-giai-nhay.test.mjs 2>&1 | grep -E '^(PASS: BG1|PASS: BG2)'`
→ hai dòng. BG4/BG6 vẫn đỏ (đúng — chưa tới lượt).
**Phục vụ:** AC-1 · AC-2 · `independent: false`
