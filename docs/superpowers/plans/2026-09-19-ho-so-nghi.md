# Hồ sơ nghỉ — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Một dòng sổ quyết định có người và lý do làm hồ sơ đã ký nhưng chết tiền đề rời khỏi ba luật của cổng, mà không sửa một byte chữ ký; bốn bộ đọc cùng hỏi một hàm.

**Architecture:** Thêm một vị từ thuần `hoSoNghi(texts)` vào `lib/workspace-record.cjs` (nơi mọi bên đọc `_acceptance/<slug>/` đã hỏi chung). Cổng bash hỏi nó qua `node -e` theo đúng khuôn luật làn eval đã dùng ở `pre-merge-check.sh:1296`. Bộ quét và bộ kiểm lại gọi trực tiếp. Thẻ KHÔNG đọc sổ — nó chỉ đọc trạng thái bộ quét trả về, nên không có bản sao luật thứ hai.

**Tech Stack:** Node CommonJS (`lib/*.cjs`), Node ESM (`scripts/*.mjs`), bash 3.2 (`scripts/pre-merge-check.sh`), bộ ca `node:assert` trong `tests/scripts/*.test.mjs`.

**Spec:** `docs/superpowers/specs/2026-09-19-ho-so-nghi-design.md` — hợp đồng: `_acceptance/ho-so-nghi/contract.md` (10 AC), phép đo: `_acceptance/ho-so-nghi/evals.yaml` (E1–E11).

## Global Constraints

- **Chữ ký là sử liệu.** Không task nào được sửa `status`, `verdict`, `verified_commit`, `human_signoff` của hồ sơ nghỉ. AC-7 đo bằng băm sha256 trước/sau.
- **Đường đọc-cũ (luật kit từ 2.13.0).** Hồ sơ/kho chưa có dòng nghỉ, chưa có trạng thái mới → KHÔNG vỡ, chỉ NOTE hoặc cờ. Không migrate hàng loạt.
- **Fail-closed.** Thiếu `node`, thiếu `lib/workspace-record.cjs`, dòng thiếu vế, văn xuôi → chấm như hồ sơ đang sống, và NÓI RA (NOTE có tên), không im.
- **Giấy khai sinh phép đo (`MEASURE-BIRTH-CLAUSE`).** Mỗi phép đo mới phải có cặp hai chiều trên CÙNG fixture: đối chứng dương xanh TRƯỚC, phá vật thật thì ĐỎ với thông điệp ghim. Mỗi mũi tiêm phải `assert` rằng nó đổi được tệp trước khi tin kết quả.
- **Ma trận so BẰNG NHAU** với danh sách viết trước — một phép giữ cả chiều đỏ lẫn chiều im. Hai vế rời (`includes` cho đỏ, `!some` cho im) là hai assertion âm-tính-một-mình, CẤM.
- **Fixture do code sinh trong chính lần chạy**, đường dẫn suy từ vị trí tệp ca (`import.meta.url`), không hardcode gốc kho. Bản sao cây để tiêm mutant lấy TRỌN thư mục bằng `git archive <sha> scripts lib`, không chép danh sách tệp tay.
- **Luật diff-chỉ-thêm (DV5)** ở `pre-merge-check.sh`: chèn nhánh mới TRƯỚC nhánh cũ, giữ nguyên văn dòng cũ.
- **Enum `type` của sổ quyết định** thêm đúng một giá trị: `nghi`. Chuỗi không dấu, một âm tiết, khớp nếp `descope|approach|fix|revisit|seal`.
- **Tên trường máy đọc, chốt một lần, không đổi về sau:** `type: "nghi"` · `by` · `decision` · `at` · `supersedes`. Ba bên dùng chung: khối lệnh trong `GUIDE.md` (bên VIẾT), `hoSoNghi()` (bên ĐỌC), tệp ca (bên ĐO).

```js
// ── Hồ sơ NGHỈ ───────────────────────────────────────────────────────────────
// Sự thật «nghỉ» là một DÒNG SỔ, không phải một status: chữ ký là sử liệu, nên
// không bộ phận nào của kit được sửa tệp đã ký để nói một điều mới. Vị từ ở ĐÂY
// vì bốn bên đọc (cổng trước-merge · kiểm lại bằng chứng · bộ quét · thẻ qua bộ
// quét) phải cho CÙNG một câu trả lời — bản sao thứ hai là lớp lỗi hai-bộ-đọc
// mà chính tệp này sinh ra để đóng.
const NGHI_VE = ['by', 'decision', 'at'];
function hoSoNghi({ ledgerText = null, contractAtRoot = true, suLieuContract = false } = {}) {
  if (ledgerText != null) {
    const dong = [];
    for (const l of String(ledgerText).split('\n')) {
      if (!l.trim()) continue;
      try { const e = JSON.parse(l); if (e && typeof e === 'object' && !Array.isArray(e)) dong.push(e); }
      catch { /* dòng hỏng: bỏ qua, cùng nếp với mọi bộ đọc sổ (gate-card readLedger) */ }
    }
    // Dòng nghỉ CUỐI thắng; một dòng sau nó mang `supersedes` trỏ đúng id ấy thì
    // nghỉ hết hiệu lực — mở lại đưa hồ sơ về ĐÚNG luật cũ (chặt hơn), nên bỏ
    // qua `supersedes` là fail-OPEN, không phải một đơn giản hoá vô hại.
    const nghi = [...dong].reverse().find(e => e.type === 'nghi');
    if (nghi) {
      const goBo = dong.some(e => e.supersedes && String(e.supersedes) === String(nghi.id));
      if (!goBo) {
        const thieu = NGHI_VE.filter(k => {
          const v = nghi[k];
          if (typeof v !== 'string' || !v.trim()) return true;
          return k === 'at' ? Number.isNaN(Date.parse(v)) : false;
        });
        if (thieu.length) return { kieu: 'dong-so-thieu', thieu: thieu.sort() };
        return { kieu: 'dong-so', by: nghi.by.trim(), at: nghi.at.trim(),
                 ly_do: nghi.decision.trim(), id: String(nghi.id || '') };
      }
    }
  }
  // Đường đọc-cũ: kit tự cho một hồ sơ nghỉ (17/09) bằng cách chuyển hợp đồng
  // vào `su-lieu/`. Cổng vốn mù với hình dạng đó vì đường dẫn — nhận ra nó là
  // cách DUY NHẤT để nói ra một lỗ fail-open đang được dùng làm nghi thức.
  if (!contractAtRoot && suLieuContract) return { kieu: 'su-lieu-cu' };
  return null;
}
```
