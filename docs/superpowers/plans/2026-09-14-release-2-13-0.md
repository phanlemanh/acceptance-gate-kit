- [ ] **Step 2: Đổi `scan()` sang liệt kê tệp git theo dõi**

Thay trọn hàm ở `tests/plugins/run-tests.sh:2089-2100`. Giữ NGUYÊN hai bộ lọc `SKIP_TOP` và `SKIP_INFRA` — chúng là lời khai AC-10 của kho, không thuộc nhát vá này.

```python
def scan(base):
    # Vật được đo là cây NGUỒN — tập tệp git THEO DÕI — chứ không phải kiểm kê tệp
    # của cây LÀM VIỆC. `rglob` với mẫu bắt-tất-cả đếm cả tệp nháp không-được-theo-dõi
    # của bất kỳ tác tử nào trong bầy, nên nó đỏ về một kho hoàn toàn lành: lớp
    # «hạ tầng tự sinh tín hiệu đỏ» đã đếm SÁU lần qua bốn cửa sổ (2.12.0 §4; lượt
    # chấm 4 của khoi-tim-loi-tra-phi-theo-vat). Giới hạn đã khai ở AC-5 của hồ sơ
    # release-2-13-0: tệp nguồn MỚI chưa vào index là vô hình cho tới khi được add.
    r = subprocess.run(["git", "-C", str(base), "ls-files", "-z"],
                       capture_output=True, check=False)
    if r.returncode != 0:
        raise AssertionError(
            f"scan: '{base}' khong phai kho git hoac git ls-files that bai "
            f"(ma {r.returncode}) — khong co nen de do")
    out = []
    for name in r.stdout.decode("utf-8", "surrogateescape").split("\0"):
        if not name:
            continue
        p = base / name
        if not p.is_file():
            continue
        rel = Path(name).parts
        if rel[0] in SKIP_TOP:
            continue
        if any(x in SKIP_INFRA for x in rel):
            continue
        out.append(p)
    return out
```

```python
def dung_ban_sao(src_root, dst):
    """Bản sao cho chiều đỏ nội tại: rsync rồi khởi tạo thành kho git.

    Sau khi `scan()` đi theo tệp git theo dõi, một bản sao KHÔNG phải kho git
    làm phép đo nổ vì HẠ TẦNG chứ không vì vật. `git add -A` đưa mọi tệp đã chép
    vào index, nên tệp tiêm ở các bước dưới VẪN được đếm — chiều đỏ nội tại giữ
    nguyên độ nhạy.
    """
    if dst.exists():
        shutil.rmtree(dst)
    subprocess.run(["rsync", "-a", "--exclude", ".git", "--exclude", ".claude",
                    "--exclude", "plugins", "--exclude", "node_modules",
                    f"{src_root}/", f"{dst}/"], check=True)
    subprocess.run(["git", "-C", str(dst), "init", "-q"], check=True)
    subprocess.run(["git", "-C", str(dst), "add", "-A"], check=True)
```
